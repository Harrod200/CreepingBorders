LUENA CONTIGUITY FLOW ANALYSIS
==============================

This document traces the exact flow of how Luena's contiguity is determined based on
whether it's classified as coastal or noncoastal.

SCENARIO 1: IF LUENA IS COASTAL
================================

Flow for a coastal continent:

Pass 1 (BFS Adjacency):
  1. Start BFS from nation capital
  2. Traverse through adjacent regions owned by nation
  3. If Luena is NOT adjacent to capital → NOT added to FullyContiguousRegions
  4. Result: Luena remains in discontiguous set

Pass 2 (Distance-based Detection):
  1. Filter regions: IsCoastal + IsContinent → Luena INCLUDED (because coastal)
  2. Get distance from Luena to FullyContiguousRegions
  3. If distance ≤ ClaimIslandsDistanceKM (typically 1000 km)
	 → Luena added to FullyContiguousRegions (FULLY CONTIGUOUS)
  4. Else if distance ≤ 2000 km (extended)
	 → Luena added to ExtendedDistanceRegions (PARTIALLY CONTIGUOUS)
  5. Else
	 → Luena not added (remains discontiguous)

Pass 3 (Bridge Detection):
  1. Find coastal islands adjacent to FullyContiguousRegions
  2. BFS through islands to find connected regions
  3. If Luena is adjacent to a coastal island → Luena added to FullyContiguousRegions

Final Discontiguity Check:
  1. Is Luena in FullyContiguousRegions? → NOT discontiguous (end)
  2. Is Luena in ExtendedDistanceRegions? → PARTIALLY DISCONTIGUOUS (end)
  3. Is Luena in discontiguous set?
	 a. Check if reachable through allied territory
	 b. If YES → PARTIALLY DISCONTIGUOUS (ally-reachable)
	 c. If NO → FULLY DISCONTIGUOUS

SCENARIO 2: IF LUENA IS NONCOASTAL
===================================

Flow for a noncoastal continent:

Pass 1 (BFS Adjacency):
  1. Start BFS from nation capital
  2. Traverse through adjacent regions owned by nation
  3. If Luena is NOT adjacent to capital → NOT added to FullyContiguousRegions
  4. Result: Luena remains in discontiguous set

Pass 2 (Distance-based Detection):
  1. Filter regions: IsCoastal + IsContinent → Luena EXCLUDED (because noncoastal)
  2. Luena is NOT processed by distance-based detection
  3. Result: Luena remains discontiguous (no extended distance classification)

Pass 3 (Bridge Detection):
  1. Find coastal islands adjacent to FullyContiguousRegions
  2. BFS through islands to find connected regions
  3. If Luena is adjacent to a coastal island → Luena added to FullyContiguousRegions
  4. (If island connects through other islands to Luena, it gets added)

Final Discontiguity Check:
  1. Is Luena in FullyContiguousRegions? → NOT discontiguous (end)
  2. Is Luena in ExtendedDistanceRegions? → (should be empty for noncoastal) (end)
  3. Is Luena in discontiguous set?
	 a. Check if reachable through allied territory
	 b. If YES → PARTIALLY DISCONTIGUOUS (ally-reachable)
	 c. If NO → FULLY DISCONTIGUOUS ✓ (expected for separated noncoastal)

EXPECTED OUTCOMES:
==================

For a COASTAL Luena:
  - Should see IsCoastalRegion returning TRUE
  - Should see Pass 2 processing it
  - Outcome: FULLY or PARTIALLY CONTIGUOUS (depending on distance)
  - OR if far from contiguous: FULLY or PARTIALLY DISCONTIGUOUS (depending on allies)

For a NONCOASTAL Luena:
  - Should see IsCoastalRegion returning FALSE
  - Should see "NOT adding to candidates" in Pass 2
  - Should NOT be in ExtendedDistanceRegions
  - Outcome: FULLY or PARTIALLY DISCONTIGUOUS (depending on BFS/allies)
  - Expected: FULLY DISCONTIGUOUS (if truly separated and no allies)
