HOW TO ENABLE:
==============

The debug logging is automatically enabled when ANY of these trace lines appears in the logs.
It uses the region name matching to trigger logging, so it will not spam - only Luena-related operations are logged.

WHAT TO LOOK FOR:
=================

If Luena is showing as PARTIALLY DISCONTIGUOUS when it should be FULLY DISCONTIGUOUS:

Check these possibilities in order:
1. Is Luena being added to extendedRegions in Pass 2?
   - If yes, check if it's being classified as an Island or Coastal Continent
   - It should be skipped (not added to candidates) if it's a Noncoastal Continent

2. Is Luena in extendedRegions causing the partial discontiguity?
   - If yes, that's the issue - a noncoastal region shouldn't use distance-based detection

3. Is Luena being found as ally-reachable?
   - If yes, check the BFS path - which ally is it connecting through?
   - For a noncoastal continent, this might be correct (if nation has allies)

4. Are there no allies but Luena is still partial?
   - If yes, check if it's in extendedRegions (case #2)
