COASTAL REGION LOGIC ANALYSIS
=============================

PROBLEM IDENTIFIED:
===================

Luena is being classified as COASTAL, but the reason needs investigation. The logs will now show us exactly WHY.

TWO DIFFERENT COASTAL DEFINITIONS:
==================================

1. **IsCoastalIsland()** (line 763)
   - Purpose: Determine if an ISLAND is coastal
   - Definition: An island is coastal if it's ADJACENT TO ANY CONTIGUOUS REGION
   - Logic: Checks if any neighbor is in the nation's contiguous regions
   - Used: During bridge detection (Pass 3) to find islands that connect to the mainland

2. **IsCoastalRegion()** (line 785)
   - Purpose: Determine if a CONTINENT is coastal
   - Definition: A continent is coastal if it has WATER NEIGHBORS (neighbor.onTheWater == true)
   - Logic: Checks if any neighbor is marked as being on water
   - Used: During distance-based detection (Pass 2) to decide if continents can use distance-based contiguity

POTENTIAL ISSUE WITH IsCoastalRegion:
======================================

The definition "has water neighbors" might be too broad:
- A region could have neighbors that are on water (like small islands)
- But NOT be strategically coastal in the game's geographic sense
- This could cause a region to be misclassified as "coastal continent" when it should be "noncoastal continent"

LUENA SPECIFIC DEBUGGING:
=========================

The debug logging added will show:

1. Is Luena in the coastal region cache?
   [DEBUG] IsCoastalRegion(Luena): Cache hit - returning [true/false]

2. What neighbors does Luena have?
   [DEBUG] IsCoastalRegion(Luena): Checking neighbor [NeighborName], onTheWater: [true/false]

3. Which neighbor(s) have onTheWater == true?
   [DEBUG] IsCoastalRegion(Luena): Found water neighbor - marking as coastal

4. Final classification:
   [DEBUG] IsCoastalRegion(Luena): Final result - isCoastal: [true/false], water neighbors found: [count]

WHAT WATERNEIGHBOR MEANS:
=========================

In Terra Invicta, neighbor.onTheWater likely means:
- The neighbor is a water tile/region (ocean, sea, etc.)
- OR the neighbor is a coastal region in geographic game terms
- This is used by the game engine to determine what regions are truly coastal

LUENA INVESTIGATION STEPS:
==========================

When you see the logs:

Step 1: Check if Luena has water neighbors
   - Look for: [DEBUG] IsCoastalRegion(Luena): Found water neighbor - marking as coastal
   - This shows what neighbor has onTheWater == true

Step 2: Verify the neighbor
   - Check if this water neighbor makes sense geographically
   - Is it a real water region?
   - Or could it be a misclassified region?

Step 3: Understand why it matters
   - If Luena is coastal, it will use distance-based detection in Pass 2
   - This could make it "extended distance" if close to other contiguous regions
   - Then it would be marked as PARTIALLY DISCONTIGUOUS

CORRECT BEHAVIOR:
=================

For a NONCOASTAL region:
1. Should NOT have water neighbors (or have water neighbors that are irrelevant)
2. IsCoastalRegion(Luena) should return FALSE
3. Should be excluded from Pass 2 distance-based detection
4. Should only achieve contiguity via Pass 1 (BFS adjacency) or Pass 3 (bridge detection)
5. If separated, should only be PARTIALLY DISCONTIGUOUS via ally-reachable BFS

For a COASTAL region:
1. Should have water neighbors (neighbor.onTheWater == true)
2. IsCoastalRegion(Luena) should return TRUE
3. Should be included in Pass 2 distance-based detection
4. Can become fully contiguous if within distance to contiguous regions
5. Can become partially contiguous if within extended distance
